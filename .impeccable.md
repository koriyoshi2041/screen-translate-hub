# Design Context

## Users and context

The owner confirmed the primary walkthrough audience: Windows users reading everyday applications and web pages. They need screen translation without leaving the material they are reading. This includes a first-time user discovering the tool and a returning keyboard user translating repeatedly.

## Jobs to be done

- Select text on screen and understand it in the chosen language.
- Keep reading while continuous translation updates after navigation.
- Compare the original, adjust readability, and stop or hide translation quickly.
- Ask the screen-aware assistant a follow-up question.
- Optionally watch a shared source in a local-network browser.

## Usability direction

Prioritize clear entry points, visible processing and pause states, reversible actions, and plain labels. Keep ordinary reading controls ahead of advanced provider configuration. Preserve the Windows tray and keyboard workflows. Use synthetic material for test captures and public documentation.

This records the confirmed audience and task priorities; it does not establish a new visual brand or replace the current visual design.
