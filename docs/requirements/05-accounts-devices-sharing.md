# 账号、设备与共享

本文规定用户能直接感知的账号、设备接入、服务开放和屏幕共享规则。

## 1 一个主人，多台设备

一套部署服务一个主人。主人登录后可以接入自己的多台设备，包括多台 Windows 电脑，以及用来观看的手机和电脑浏览器。

首版不提供多人独立空间和成员角色。是否增加可撤销的访客观看分享，列入 [待定事项](open-questions.md)。

## 2 登录

平台自带登录，不依赖其他账号系统。主人使用账号和密码登录，并可以额外开启验证器二步验证，即基于时间的一次性密码（Time-based One-Time Password，TOTP）。

## 3 Windows 设备接入

### 3.1 三个依次设置的开关

Windows 客户端与后台的关系由三个开关分别控制。后一个开关以前一个为前提：开启联网需要先登录，开放服务需要先开启联网。

| 开关 | 打开后的效果 |
| --- | --- |
| 登录 | 这台 Windows 成为主人的设备 |
| 开启联网 | Windows 主动连接后台，可以参与跨设备的工作流 |
| 开放服务 | 后台和其他设备可以调用这台 Windows 上被逐项选中的本机服务 |

Windows 主动连接后台，主人不需要为每台电脑单独开放公网端口。

### 3.2 可开放的本机服务

Windows 登录并开启联网后，可以把以下本机服务开放给后台。每项服务由用户在 Windows 客户端上单独勾选，未勾选的服务只供本机使用。

| 服务 | 接收 | 产生 |
| --- | --- | --- |
| OCR | 图片 | 文字与包围框 |
| 翻译 | 某种语言的文字 | 目标语言的译文 |
| 卡片显示 | OCR 结果和对应图片 | 在这台电脑上显示浮卡 |
| AI 提示 | AI 的评价或回答 | 在这台电脑的鼠标旁显示 |

### 3.3 Windows 只管理自己

每台 Windows 只管理自己的本机服务。本机服务使用的引擎、凭据和开放范围，都在这台 Windows 的客户端上配置。

网页端的工作流只能选用已经开放的服务，并填写该服务允许的调用参数。后台不能绕过 Windows 上的开放设置调用未开放的服务。

## 4 屏幕共享

### 4.1 由源电脑主动开启

屏幕采集和共享必须在源电脑上主动开启。网页端无法远程开启某台 Windows 的屏幕采集。

### 4.2 处理服务与屏幕共享分开授权

开放某项处理服务，只允许其他设备把数据发给这项服务处理。例如，电脑 A 开放了 OCR 和本地翻译，没有开启屏幕共享：其他设备可以把图片发给 A 做 OCR、把文字发给 A 翻译，但无法取得 A 的屏幕画面。

## 5 观看

主人在手机或电脑浏览器上登录后，来源列表中显示所有已经开启共享的 Windows。主人从中选择一路观看，同一时刻只显示一路。

同一路来源可以被多个设备同时观看。所有观看端共用这一路的翻译目标语言、翻译结果和显示设置。

观看会话能够访问的范围列入 [待定事项](open-questions.md)。

## 6 跨设备调用

不同设备之间的数据传递和服务调用，统一经过后台转发。观看端也通过后台取得画面和译文。

一次运行只调用它的工作流中明确连接的服务。某项服务即使已经开放，没有连接到当前工作流中，这次运行也不会调用它。
