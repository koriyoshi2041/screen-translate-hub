# 待定事项

本文列出需求整理中已经识别、但尚未确定的问题。每一项确定后，结论写入对应的需求文档，并从本清单移除。

## 1 产品范围

1. 访客观看分享。首版保持一套部署一个主人。待定的是是否增加可撤销的访客观看分享，或者进一步支持多个账号各自拥有独立的设备、工作流和记录。
2. 观看会话的访问范围。待定的是只用于观看的会话能访问哪些内容，例如只能读取指定来源的画面与译文，不能编辑工作流、调用自定义 HTTP 接口节点或读取模型凭据。
3. 其他桌面操作系统。桌面端首版面向 Windows，macOS 和 Linux 的支持时间待定。
4. 持续屏幕的范围切换。固定范围与跟随活动窗口两种方式首版都要提供，两者之间如何切换待定。
5. 多语言验收样本。平台不预设重点语言对，验收需要选定一组具体的语言和内容样本，例如横排与竖排、多栏文档、漫画对话气泡。
6. 展示效果的扩展顺序。首版只实现整幅画面降低亮度，半透明遮罩、高斯模糊等效果的引入顺序待定。
7. 画面刷新策略。首版默认显示当前正在处理的截图，画面刷新策略保留配置能力。其他可选策略的具体内容待定，候选包括：实时显示最新的原画面，同时撤下与之不匹配的旧文字层；整幅画面的译文全部完成后再更新画面。

## 2 工作流

1. 节点编辑器的位置。节点编辑器在 Windows 本机界面和网页端之间如何分工待定，包括 Windows 独立使用时能否编辑本机工作流。
2. 节点清单与连线数据。完整的节点清单，以及每种连线上传递的数据格式，在 spec 阶段确定。
3. 划词翻译的竞速。划词入口的翻译是否同样使用多翻译源竞速，以及选中的文字如何划分翻译单元，待定。

## 3 运行参数

1. 默认值。定时触发的默认截屏间隔、变化检测阈值、各节点超时和批次总时限的默认值待定。
2. 手动重试与批次总时限。用户在运行详情中手动重试某个节点或翻译源时，是否仍受原批次总时限约束，待定。
3. 事件触发的规则。鼠标点击、键盘操作和快捷键触发在后续版本提供，具体规则待定，例如操作后等待多久再截屏、哪些按键计为触发、能否与定时触发同时启用。

## 4 账号与设备

1. 设备配对方式。Windows 成为主人设备的具体配对流程待定，例如由主人在后台生成一次性配对码。
2. 撤销设备。主人撤销某台设备后，正在进行的运行、共享和观看如何结束，待定。

## 5 部署

1. 家庭部署的公网接入。家庭电脑或 NAS 没有公网入口时，异地设备通过什么方式访问家庭后台，方案待定。

## 6 数据

1. 历史记录容量。历史记录的容量上限和清理规则待定。
2. 本机与后台的数据合并。Windows 独立使用时产生的历史记录和本机工作流，在重新连接后台后是否同步、如何处理冲突，待定。
